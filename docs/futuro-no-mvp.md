# Funcionalidades fuera del MVP

Estas funcionalidades quedan explícitamente fuera de la etapa inicial y se evaluarán en fases posteriores:

- Alta online de generadores.
- Reclamos mediante sistema web.
- Facturación online.
- Portal o área privada para clientes o generadores.
- Trámites administrativos online.
- Automatización de pagos.
- API de Mercado Pago.
- Webhooks.
- Notificaciones automáticas.
- Aplicación automática del descuento.
- Sistemas internos de gestión.
- Suscripción o registro de generadores como mecanismo activo hasta definir su finalidad y procesos.

> La suscripción de generadores no debe tratarse como una newsletter simple en esta etapa.
