# Alcance del MVP

El MVP de la nueva web de TeCMA San Juan incluirá únicamente lo siguiente:

- Landing institucional informativa.
- Información institucional de la organización.
- Información de contacto y medios para comunicarse.
- Sección dedicada al formulario de contacto.
- Sección que muestre el QR de Mercado Pago vigente como recurso estático.
- Documentación del beneficio del 5 % y la regla de vigencia del descuento.

### No incluye en esta fase

- Gestión de usuarios o portal privado.
- Automatización de pagos.
- API de Mercado Pago o integración de pagos.
- Webhooks o conciliación automática.
- Identificación automática de pagadores.
- Facturación online.
- Alta online de generadores.
- Reclamos mediante sistema web.
- Área administrativa expuesta al usuario.
