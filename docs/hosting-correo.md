# Hosting y correo

## Situación actual

- El hosting actual de la web está en DonWeb.
- El dominio, DNS y correo se deben preservar en cualquier migración futura.

## Riesgos de migración

- Cambiar de hosting sin planificar correctamente puede interrumpir el servicio.
- Una migración mal gestionada puede afectar el dominio, los registros DNS y la entrega de correo.
- El correo debe mantenerse operativo durante cualquier cambio de infraestructura.

## Continuidad requerida

- No se debe cambiar el hosting en esta etapa.
- No se debe cambiar el dominio en esta etapa.
- No se debe cambiar la configuración de DNS en esta etapa.
- No se debe cambiar el correo en esta etapa.
- Cualquier migración futura debe preservar correctamente dominio, DNS y correo.
