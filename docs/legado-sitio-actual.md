# Sitio antiguo como referencia

## Propósito

Este documento describe los criterios para revisar el sitio anterior de TeCMA San Juan.
El sitio previo se considera material de referencia y no debe usarse como fuente exclusiva de decisiones.

## Criterios futuros para la revisión

- Identificar contenido reutilizable que siga siendo válido.
- Detectar información desactualizada o inconsistente.
- Evaluar imágenes y assets que pueden conservarse o reemplazarse.
- Reconocer funcionalidades obsoletas que no deben migrarse al nuevo MVP.
- Documentar recursos que deben conservarse por valor comunicativo.
- Verificar el QR vigente frente al QR realmente utilizado actualmente por TeCMA.

## Reglas de uso

- No asumir la estructura del sitio antiguo.
- No reutilizar automáticamente ningún contenido sin revisión.
- La nueva web no debe depender del código del sitio anterior.
- El sitio anterior puede revisarse en una etapa separada.
